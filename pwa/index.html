🧀 Um passo de cada vez

Esta é a primeira versão do PWA. Vamos melhorar o perfil, a loja e os minijogos aos poucos, sem simular compras nem inventar integrações.

Use a conta que você já tem no portal ou crie uma conta nova.

A API de contas é a mesma usada pelo portal atual.

Sua senha é enviada por HTTPS à API Ratópolis. Nunca compartilhe sua senha ou token.

🎮 MiniGames

Os jogos offline não precisam de conta. Os jogos online ficam disponíveis dentro do PWA depois que você entrar.

📴 Jogos offline

Esta área fica aberta sem login. Ainda não encontrei arquivos de minijogos offline publicados no repositório; quando os arquivos oficiais forem adicionados, eles aparecerão aqui sem exigir conta.

🌐 Jogos online

Entre na sua conta para acessar os minijogos online.

Conta conectada. Os links dos minijogos online serão adicionados quando os endereços oficiais estiverem confirmados.

🛍️ Loja da toca

A loja ficará aqui quando a API oficial de catálogo e compras estiver confirmada. Nenhuma compra ou saldo é simulado nesta versão.
