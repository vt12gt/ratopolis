🐀 RATIVASNACK — SERVIDOR AUTORITATIVO
======================================

ESTRUTURA:
  shared/sim.js       → Coração do jogo (usado por servidor e cliente)
  server/server.js    → Servidor WebSocket dedicado
  server/package.json → Dependências do servidor
  client/index.html   → Jogo com conexão ao servidor

COMO RODAR LOCAL:
  1. Instale o Node.js → nodejs.org
  2. Abra terminal na pasta "server"
  3. Execute: npm install
  4. Execute: npm start
  5. Servidor estará em: ws://localhost:8080

COMO HOSPEDAR ONLINE:
  Opções recomendadas: Render.com, Railway.app, Fly.io
  Faça upload da pasta "server" para a plataforma
  Atualize SERVER_URL no client/index.html com sua URL

CÓDIGO COMPARTILHADO:
  Altere sempre shared/sim.js — servidor e cliente usam a mesma lógica
