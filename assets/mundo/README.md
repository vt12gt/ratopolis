# Ratópolis — assets do mundo

Pasta dos recursos visuais do Lobby 2.5D.

- `ratinho-sprites.svg`: folha com 4 poses do ratinho para animação em Canvas.
- `casa-lobby.svg`: construção medieval em vista isométrica.
- `arvore-lobby.svg`: árvore em camadas com sombra.

Os arquivos são carregados pelo HTML principal e desenhados no Canvas. Os pontos de entrada das construções são tratados pelo código do jogo, não por imagens.
